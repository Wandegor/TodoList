## Сервис Todo list позволяющий вести список задач.

### Технологии:
* Язык: GO
* Бд: PostgreSQL
* Api: RestAPI
* Формат данных: json
* Контейнеризация: Docker, Docker Compose
* ORM: GORM

### Описание Api:

1. `GET /tasks` - Получение невыполненных задач. (возвращает список НЕвыполненных задач)

2. `POST /tasks` -Создание задачи. Тело запроса: `{ "text": "лорем ипсум" }`

Ограничение: текст задачи не может содержать более 1000 символов и не может быть пустым.

3. `PATCH /tasks/{id}` - Пометка задачи как выполненной
4. `DELETE /tasks/{id}` - Удаление задачи

5. `GET /tasks/archive` - Получение архивных задач (возвращает список выполненных задач)

Запуск проекта: `docker compose -f build/docker-compose.yaml up -d database`

Запуск тестов(из корня): `go test ./tests -v`
